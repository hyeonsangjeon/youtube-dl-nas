These pages cover installation, upgrades, troubleshooting, dashboard operation,
and mobile sharing. Shared URLs and credentials travel directly between your
phone and your own NAS.

The application UI supports English, Korean, Simplified Chinese, and Polish. It detects a supported browser language on first use and remembers an explicit language selection.
