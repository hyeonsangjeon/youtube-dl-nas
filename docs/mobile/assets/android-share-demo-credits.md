# Android Share Demo Credits

`android-share-demo.mp4`, `android-share-demo.gif`, and
`android-share-demo-poster.jpg` show a real Galaxy Z Flip sharing a YouTube link
through HTTP Shortcuts and playing the downloaded file from youtube-dl-nas.
Recorded on October 17, 2026, with NAS application version 26.0922.

The recording is edited for brevity, with personal details hidden and English
captions added. The shortcut was configured before recording. It is not an
uninterrupted timing benchmark or an HTTPS PWA demonstration.
